# HRMS Prototype

This repository contains a simple HRMS (Human Resource Management System) that showcases multiple modules inspired by Keka HRMS. The data is stored in-memory and the system is suitable for demos or experimentation.

## Features
- Employee management
- Attendance tracking
- Leave requests
- Payroll entry management
- Performance goals and reviews
- Training course assignment
- Basic recruitment flow
- Simple analytics and AI-based attrition prediction

Run `python demo.py` to see an example usage.
